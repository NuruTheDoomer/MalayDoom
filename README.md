# MalayDoom

**A Malay localization project for Classic Doom. It's Doom, but in Bahasa Melayu!**

MalayDoom is an unofficial fan-made project that localizes Classic Doom and related releases into Malaysian Malay.

> **This project is not affiliated with, sponsored by, or endorsed by id Software or Bethesda.**

> *The first revision of this project will be released on October 28th.*

> Untuk baca versi bahasa Melayu README ini, boleh pergi ke [sini](README-BM.md)!

## Supported Games

MalayDoom Revision 1 will include localization WADs for:

- The Ultimate Doom

- Doom II

- Final Doom (TNT: Evilution and The Plutonia Experiment)

- Master Levels for Doom II (PSN and KEX versions)

- No Rest for the Living

- SIGIL and SIGIL II

- Legacy of Rust

Master Levels has separate PSN and KEX WADs because the two releases use different map orders.

## Download

Download the latest release from [**GitHub Releases**](https://github.com/NuruTheDoomer/MalayDoom/releases).

The complete release archive includes the localization WADs, documentation, and other relevant files. Individual WADs and optional compatibility addons are also available where applicable.

A separate DOS-compatible distribution is available for supported games for use with compatible DOS source ports like Boom and MBF.
