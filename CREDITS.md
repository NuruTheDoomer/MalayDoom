# Credits

Below are the credits for the websites and tools used in the development of MalayDoom, along with attributions to the original works from which the localized graphics are derived.

---

[**SLADE3**](https://slade.mancubus.net/index.php) - The program that I use for general WAD editing work

[**WhackEd4**](https://www.teamhellspawn.com/exl/whacked4/) - The original program that I used for the DeHackEd side of things

[**DoomWriter**](https://github.com/Visual-Vincent/DoomWriter) - The original program that I used for generating the menu and level name graphics

[**eevee's Doom Text Generator**](https://c.eev.ee/doom-text-generator/) - The website that I currently use for generating the menu and level name graphics

[**Cacoco**](https://github.com/lizzieshinkicker/Cacoco) - The UMAPINFO editor that I use during the development of the UMAPINFO definitions for some of the localization WADs

[**Crowdin**](https://crowdin.com) - The translation platform I use to host the translations, which I'm already used to using because of the Minecraft translation works :)

**elf-alchemist's [UMAPINFO menu graphic template](https://gist.github.com/elf-alchemist/da9152816cae79ba5a9c2f7463878f6e)** - The template which I use with the Doom Text Generator's bulk generator feature to generate the menu graphics, which makes me aware of a few more translatable port-specific menu graphics

**PhobosVB's [Ultra-Widerpix854 project](https://www.doomworld.com/forum/topic/148537-ultra-widerpix854-329-super-ultrawide-assets-and-skies-for-the-doom-and-raven-games/)** - The base 32:9 STBAR texture for the
Widescreen Status Bar WAD

**NightFright2k19's [Widescreen Statusbars project](https://github.com/NightFright2k19/doom_widehud/)** - The old 21:9 STBAR
texture for the Widescreen Status Bar WAD

**id Software, TeamTNT, Nerve Software, Romero Games, Nightdive Studios, MachineGames** - The original graphics that are (or will be) localized, and, of course, the original games and expansions themselves!
